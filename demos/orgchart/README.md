# Organization Chart Demo

This demo shows how to create an interactive organization chart from JSON data and then export it to the VSDX file format.

## Things to Try

- Press ![export](./public/download-16.svg) to export the graph to the VSDX file format.
- Try different zoom levels and export the graph to VSDX file format to see that the exported graph is consistent with the current level of details of the graph component.
